# Contributing

Thank you for your interest in HD Wallet.

## Documentation

See [docs/CONTRIBUTING.md](docs/CONTRIBUTING.md) for development setup, project structure, and pull request guidelines.

## Quick start

```bash
pnpm install
pnpm dev
```

## Before opening a PR

1. Run `pnpm test` and `pnpm typecheck`
2. Run `pnpm format:check`
3. Describe security implications if touching crypto, vault, or worker code

## Code of conduct

This project follows the [Contributor Covenant](CODE_OF_CONDUCT.md).
