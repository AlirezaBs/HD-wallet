# Security Policy

## Reporting a vulnerability

If you discover a security issue, please **do not** open a public GitHub issue.

Report it privately to: **alirezababazadehsk@gmail.com**

Include steps to reproduce, affected versions, and impact if known. We aim to acknowledge reports within a few business days.

## Scope

This policy covers HD Wallet client-side cryptography, vault storage, signing flows, and the Web Worker security boundary.

For detailed security architecture, see [docs/SECURITY.md](docs/SECURITY.md) and [docs/THREAT_MODEL.md](docs/THREAT_MODEL.md).

## Supported versions

Security fixes are applied to the latest release on the `main` branch.
